Get started

Free to run — you bring the key.

Shoebox is a Mac app (Apple Silicon only, for now). The app is free; the only cost is your own OpenRouter usage, billed to you. Three steps and you’re filing:

01 — Download

Get the app

Grab the latest Shoebox for Apple Silicon (a ~250 MB .zip), unzip it, and drag Shoebox into your Applications folder.

Download for Apple Silicon

If macOS says it’s from an unidentified developer, right-click the app and choose Open once. From then on it updates itself.

02 — Bring a key

Get an OpenRouter key

Shoebox reads and answers using models on OpenRouter. Create a free account and an API key — it starts with sk-or-. You only pay OpenRouter for what you actually use.

Get an OpenRouter key
03 — Paste & go

Add your key, once

Open Settings → OpenRouter API key, paste it in, and Save. The key is stored only on your Mac and only ever talks to OpenRouter. Now drop a document in — or just ask.
